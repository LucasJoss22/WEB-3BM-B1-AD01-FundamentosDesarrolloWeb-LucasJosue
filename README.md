# DriveFix - Sistema Web de Mantenimiento Automotriz

Proyecto desarrollado para la asignatura **Programación Web 1** - Unidad 1 (Práctica 1 / AD01).

## 📌 Descripción del Proyecto
DriveFix es una aplicación web frontend para un taller mecánico automotriz que permite:
- **Página Institucional:** Inicio con carrusel, sección "Acerca de", catálogo de servicios, contacto, integración de WhatsApp y Google Maps.
- **Portal del Cliente:** Consulta y edición de perfil y vehículo, solicitud de mantenimientos con formulario completo y seguimiento de estado en tiempo real.
- **Panel del Administrador:** CRUD completo de órdenes de trabajo, cambio de estados de atención, gestión de clientes y bandeja de mensajes de contacto.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica.
- **CSS3 / Bootstrap 5:** Diseño responsivo y estilización.
- **JavaScript (ES6):** Manipulación del DOM, eventos, validaciones y métodos de arrays (`find`, `filter`, `map`, `forEach`).
- **SweetAlert2:** Alertas interactivas y confirmación de eliminación.
- **LocalStorage:** Persistencia de datos en el navegador sin base de datos.
